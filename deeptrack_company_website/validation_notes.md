# Enterprise Due-Diligence Migration Validation

Local desktop preview of the rebuilt homepage rendered successfully on August 17, 2026. The verified page presents the new enterprise due-diligence headline, the evidence-led positioning, five sector pathways—including flexible workspaces—and assessment calls to action. The supplied Wall Street image renders as the financial-services editorial hero visual, while the Deeptrack black wordmark and white footer wordmark render correctly.

The visual verification used an environment without a local Convex deployment. The root layout and client-side Convex wrapper now preserve their original authenticated composition when `NEXT_PUBLIC_CONVEX_URL` is configured, but render public marketing pages without crashing when it is not. The preview still displays Clerk’s local development helper panel; this is environment-provided development UI rather than a website component.

The production compile completes source compilation and TypeScript checks. The remaining build stop is isolated to the pre-existing `/productApi` route, where an existing component attempts to read a null React context during static prerendering. No new enterprise page was named in the build failure.

The flexible-workspaces route initially returned a 404 because the new Next.js 16 dynamic route required asynchronous `params` handling. After that correction, `/industries/flexible-workspaces` rendered successfully and was visually verified. Its content explicitly addresses co-working operators, innovation hubs, startup campuses, and managed offices; it does not refer to creative or production studios.

The expanded public-site pass was checked in local development on the workflow-assessment route and the homepage. The assessment page renders an interactive evidence and workflow intake without presenting a calculated cost, savings, risk score, or performance claim. The homepage now visibly includes routes to assessment, engagement, developer/API, partner, news, and research journeys. The desktop header exposes the retained Due diligence, Capabilities, Industries, Developers, Intelligence, Partners, and Company groups. The footer now exposes the retained public product, sector, developer, intelligence, partner, legal, Vanta Trust Center, X, and LinkedIn destinations.

The public partner route was visually verified with a secure Partner Portal path, referral, technology, and delivery conversation paths, and no public commission, tier, logo, certification, or outcome claims. The familiar `/pricing` route was also checked and redirects to the approved consultation-led engagements page, where diagnostic, advisory, prototype/build, production-hardening, training, and research pathways are listed without public price, credit, SLA, or duration commitments.

The rebuilt `/productApi` route was visually verified as a developer-facing evidence-assessment integration journey, with retained console and existing-documentation destinations plus a tailored-proposal commercial path. The retained image-authentication URL was also visually verified as an Image Evidence Assessment capability page; it now treats analysis as one layer in a wider diligence process and contains no unsupported legacy statistics, accuracy, fraud-prevention, regulatory, or outcome claims.

TypeScript validation was run after clean Next.js route-type generation and completed successfully. The production build also completed successfully when run with `NODE_ENV=production`, producing an on-demand server-rendered route inventory that includes all new and retained public paths. The sandbox’s default environment injects a non-standard `NODE_ENV`; running the production build without overriding it reproduces an inherited Next.js global-error prerender failure, so deployment validation must use the standard production environment that Vercel supplies.

SEO implementation verification: the local homepage renders the visible enterprise FAQ section and the revised footer category statement, “A due diligence company.” Browser metadata inspection confirmed the title, self-canonical `https://www.deeptrack.io/`, enterprise description, `index, follow` robots directive, Open Graph social image, Twitter card/image metadata, Organization structured data, and the route-specific FAQPage structured-data script. The expanded source build passes with `NODE_ENV=production`.

Motion verification: the rebuilt enterprise homepage and new enterprise routes use native disclosure controls plus short hover-only color and transform transitions; they do not use JavaScript-driven entrance or scroll-reveal animations that can leave content partially hidden. The rendered homepage was reviewed with its header, hero, content pathways, FAQ, and footer fully visible. A global `prefers-reduced-motion` rule now disables non-essential animation, transition delay, and smooth scrolling for motion-sensitive users. Production-mode compilation passed after this safeguard.

011: 1. GENERATE API KEY
012: -------------------
013: Endpoint: POST /keys/generate
014: Call when: User clicks "Generate Key" button
015: 
016: Request Body:
017: {
018:   "client_id": "user@email.com",
019:   "plan": "basic"
020: }
021: 
022: Response:
023: {
024:   "api_key": "dtk_xxxxxxxxxxxx",
025:   "plan": "basic",
026:   "monthly_limit": 1000
027: }
028: 
029: Plans available:
030: - "basic"      → 1000 scans/month
031: - "enterprise" → unlimited scans

049: 3. REVOKE API KEY
050: -----------------
051: Endpoint: DELETE /keys/revoke
052: Call when: User clicks "Revoke Key" button
053: 
054: Request Body:
055: {
056:   "api_key": "dtk_xxxxxxxxxxxx"
057: }
058: 
059: Response:
060: {
061:   "message": "Key revoked"
062: }

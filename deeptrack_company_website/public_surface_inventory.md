# Deeptrack Main Site — Public Surface Inventory

The extracted application contains a large public and authenticated web estate. The enterprise due-diligence repositioning must **reframe and connect this estate**, not replace it with a single landing page.

| Domain | Existing journeys to retain or rework | Enterprise due-diligence role |
|---|---|---|
| Core conversion | Homepage, contact, due-diligence, sector pages | Explain the category, guide prospects to an assessment, and establish decision-readiness value. |
| Products | Image authentication, audio authentication, Gotham, Sentinel | Reframe as evidence-assessment capabilities and workflow modules rather than independent deepfake-only products. |
| Developer/API | `/productApi`, API capability modules, API pricing, console and documentation links | Preserve the technical integration journey for identity, media, document, and provenance assessment workflows. |
| Commercial | Homepage pricing cards, API pricing cards, product CTAs | Retain engagement and deployment pathways but replace unapproved public prices, credits, SLAs, support promises, and volume claims with tailored-proposal language. |
| Risk calculator | Existing `RiskCalculator` homepage component | Rework into a transparent workflow-exposure assessment; do not publish calculated savings or efficacy claims. |
| Channel partners | Channel Partner Portal login, dashboard, leads, commissions, materials, and partner portal navigation link | Preserve as an operational route and add a public partner-pathway explanation for referrals, integrations, and enterprise delivery partners. |
| News and research | `/news`, gated news-centre portal, `/research`, research detail pages, blog pages, NACHA resource | Preserve the content destinations and reframe the entry points as Due-Diligence Intelligence and Research. |
| Company | About, company and culture, leadership, technology, careers, investor-request interactions | Preserve the company narrative and investor-access flows; refresh headings only where needed to match the new positioning. |
| Legal and trust | Legal center, privacy, terms, service-level agreement, external Vanta Trust Center | Keep all legal and verified trust destinations reachable. Do not add unsupported certifications or compliance claims. |
| Social | X `https://x.com/deeptrck` and LinkedIn `https://www.linkedin.com/company/deeptrck/` | Restore both verified social links in the comprehensive footer. |

## Existing Navigation Inventory

The existing desktop navigation contains a **Solutions** menu, a **Use Cases** menu, direct partner-portal, research, and news-center links, plus an **Investor relations** menu with request-access modals for a pitch deck, cap table, and competitor analysis. The mobile navigation has a reduced subset, so the expanded implementation must explicitly provide navigation parity instead of inheriting the current omission.

## Existing Footer Inventory

The legacy global footer exposes Home, Use Cases, About, Contact, an external Vanta Trust Center, a Legal Center, X, and LinkedIn. It also contains a large conversion call-to-action. The new footer must become more comprehensive, adding clearly structured product, sector, resource, partner, company, legal, trust, contact, and social sections while preserving those verified destinations.

## Current Rebuild Gap

The first enterprise implementation rebuilt the primary homepage, sector pages, due-diligence page, contact page, structured data, sitemap additions, and a minimal footer. It did not yet restore the complete navigation or develop the retained legacy product, developer, partner, commercial, calculator, news, research, and company journeys. This is the scope of the current expansion.
